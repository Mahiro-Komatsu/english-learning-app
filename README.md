# 🌟 LinguaFlow (リンガフロー) - 英語学習 PWA アプリケーション

スマホアプリのように快適に使える、次世代型の英語学習 Web/PWA アプリケーションです。
単語フラッシュカード暗記、英文法4択テスト、AI英会話パートナー、学習進捗ダッシュボード（ストリーク・EXP）が1つに統合されています。

---

## 🚀 主な機能

### 1. 📊 ホーム / ダッシュボード (Dashboard)
- **連続学習日数（ストリーク 🔥）**: 毎日の継続学習を可視化。
- **EXP & レベルシステム 🌟**: 単語学習やクイズ、英会話で経験値を獲得し、レベルアップ！
- **過去7日間の学習実績チャート**: 毎日の獲得XPを棒グラフで確認可能。
- **今日の名言**: 毎日変わる英語学習のモチベーションクォート。

### 2. 📚 単語帳・フラッシュカード (Vocabulary & SRS)
- **カテゴリ別プリセット単語帳**:
  - **日常英会話 (Daily Conversation)**: 毎日の会話・チャット必須表現
  - **TOEIC (TOEIC L&R Test)**: **重要度順・完全網羅 8,000単語**（Stage 1: 500点〜Stage 8: 990点満点まで目標スコア別）
  - **トラベル・海外旅行 (Travel & Hospitality)**: 空港・ホテル・観光必須表現
  - **IELTS (IELTS Academic & General)**: **重要度順・完全網羅 8,000単語**（Stage 1: Band 5.0〜Stage 8: Band 8.5-9.0最難関まで）
- **ステージ・セクション学習機能**: 8,000語の膨大な単語も、目標レベル別ステージ（各1,000語）や1回25語のセクション単位、未習得単語優先でサクサク継続。
- **重要度ランクバッジ**: 各単語に「重要度 #1」「重要度 #245」など出題順位を表示。
- **3Dカードめくり**: タップまたはクリックで表面（英語・発音・品詞）と裏面（日本語訳・例文）が滑らかに反転。
- **ネイティブ音声発音**: スピーカーアイコンでいつでもネイティブ発音（en-US / en-GB）を確認。
- **間隔反復 (SRS)**: 「覚えた！」「要復習」に自動仕分け。
- **自作単語の追加**: 自分が覚えたいオリジナル単語や例文を自由に追加可能。
- **完了時SVGバッジ＆演出 🎉**: セクション完了時に美しいSVGバッジと紙吹雪演出で達成感を演出。

### 3. 📝 英文法・穴埋めテスト (Grammar & Practice) - 【全14分野 完全網羅版】
- **全14主要文法分野を体系的に網羅**:
  1. **文型・品詞の語順 📐**: 第1〜第5文型 (SVOC)、自動詞・他動詞の識別、品詞の機能
  2. **時制・進行形・完了形 ⏳**: 現在完了・過去完了(大過去)・未来完了・時制の一致と例外
  3. **助動詞・推量・後悔 💡**: must have, should have, cannot, would rather, may well
  4. **受動態・群動詞 🔄**: 進行形受動態、完了受動態、第5文型受動態、by以外の前置詞
  5. **不定詞 (to do / 原形) 🎯**: 3用法、使役動詞・知覚動詞、完了不定詞、be to構文
  6. **動名詞・慣用表現 ⚡**: 不定詞との使い分け (remember等)、MEGAFEPS、It is no use -ing
  7. **分詞・分詞構文 🌿**: 感情を表す分詞、完了分詞構文、付帯状況のwith構文 (with O C)
  8. **関係詞 (代名詞・副詞) 🔗**: who/which/whose、前置詞+関係代名詞、what、非制限用法、複合関係詞
  9. **仮定法・条件文 💭**: 仮定法過去・過去完了、if省略の倒置、要求・提案動詞のthat節
  10. **比較表現・最上級 ⚖️**: the+比較級 the+比較級、倍数表現、ラテン比較級、no more than
  11. **前置詞・句前置詞 📍**: byとuntilの区別、forとduring、in spite of、コロケーション
  12. **接続詞 (等位・従属) 🌉**: not only A but also B、unless、whether、so that、as long/far as
  13. **主述一致・話法 🤝**: either A or B、each/every、a number of vs the number of、話法転換
  14. **否定・倒置・強調構文 🔍**: 否定語倒置 (Never have I...)、強調構文 (It is... that)、部分否定
  - **全カテゴリ総合実戦テスト 🌐**: 全14分野からランダムに10問をセレクトして実戦演習
- **即時判定＆詳細解説**: 選択後すぐに正誤がわかり、詳しい文法解説・間違いの理由・日本語全訳を表示。
- **弱点克服モード**: 間違えた問題が自動で蓄積され、「間違えた問題を復習」から集中特訓可能。

### 4. 🤖 AI英会話パートナー (Voice & Chat)
- **実践的シチュエーション**:
  - ☕ カフェで注文 (Coffee Shop)
  - ✈️ 入国審査・空港 (Airport Immigration)
  - 🏨 ホテル・リクエスト (Hotel Front Desk)
  - 💼 英語面接・自己紹介 (Job Interview)
  - 🏙️ 週末のフリートーク (Casual Weekend Chat)
- **音声認識 (STT) 🎙️**: マイクボタンを押して英語で話しかけるとリアルタイムで自動文字起こし。
- **音声読み上げ (TTS) 🔊**: AIの返答を自動でネイティブ発音読み上げ。
- **💡 ネイティブ表現アドバイス (Native Tip)**: あなたの英語に対して「より自然な言い回し」や「ワンポイント文法アドバイス」をリアルタイム提示。
- **3つのAIバックエンド**:
  1. **デモ用AIシミュレータ**: APIキーなしで即座にオフラインでも自然な対話が可能。
  2. **Google Gemini API**: 無料枠が豊富な最新Geminiモデル（Gemini 1.5 Flash / 2.0 Flash）と直接連携。
  3. **OpenAI API**: GPT-4o mini 等と直接連携。

### 5. ⚙️ 設定 & カスタマイズ (Settings)
- **発音アクセント切替**: 🇺🇸 アメリカ英語 / 🇬🇧 イギリス英語
- **再生速度調整**: 0.8倍（ゆっくり）、1.0倍（標準）、1.2倍（速め）
- **データのバックアップ・引き継ぎ**: 全学習進捗・自作単語・設定をJSONファイルでエクスポート/インポート可能。
- **ダークモード対応 🌓**: 目に優しいダークテーマとワンタップで切り替え。

## 💻 起動方法 (Windows / PC)

### 方法 1: ワンクリック起動（推奨）
フォルダ内にある **`start.bat`** をダブルクリックするだけです。
自動的にローカルサーバーが起動し、ブラウザでアプリが開きます。

### 方法 2: コマンドラインから起動
PowerShell または コマンドプロンプトで以下のコマンドを実行します：
```bash
python -m http.server 8080
```
その後、ブラウザで [http://localhost:8080](http://localhost:8080) にアクセスします。

---

## 📱 スマートフォン (iPhone / Android) でのPWAインストール方法

1. PCと同じWi-Fi環境にあるスマートフォンを用意します。
2. PCのIPアドレス（例: `http://192.168.x.x:8080`）をスマホのブラウザで開きます。
3. **iPhone (Safari)**:
   - 画面下の共有ボタン（四角から矢印が出ているアイコン）をタップ
   - **「ホーム画面に追加」** を選択
4. **Android (Chrome)**:
   - 右上のメニュー（︙）をタップ
   - **「アプリをインストール」** または **「ホーム画面に追加」** を選択
5. ホーム画面に専用アプリアイコンが作成され、ネイティブアプリのように全画面で起動できます！

## 🔑 AI APIキーの設定方法（任意）

APIキーがなくても「デモAIシミュレータ」ですぐに英会話を楽しめますが、完全自由対話を行いたい場合は設定画面からキーを入力できます：

1. アプリ内の **「設定」タブ** を開く。
2. 「利用するAIバックエンド」で **Google Gemini API** または **OpenAI API** を選択。
3. APIキーを入力して **「設定を保存する」** をクリック。
   - ※ APIキーは外部サーバーには送信されず、お使いのブラウザ内（LocalStorage）にのみ安全に保存されます。
